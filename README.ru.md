# Conduit · ARM64 Performance

[English](README.md) · [Русский](README.ru.md)

Экспериментальная сборка для личных проверок совместимости и производительности. Названия и интерфейс исходного проекта сохранены.

[Исходный проект](https://github.com/cogwheel0/conduit) · [Готовые пакеты](https://github.com/aktalascloud/conduit-arm64-performance/releases)

Скачайте **единственный APK** из последнего релиза и установите его на Android ARM64. В сборку входят свежие исходники основной ветки и проверенные патчи форка. Постоянные ID и подпись сохраняют возможность обновления. ZIP, CMD, веса LLM и личные настройки в релиз не входят. Сохранён исходный детектор речи Silero VAD (2,3 МБ); точные исходники v5.1 и лицензия MIT указаны в `.avx1/native-arm64.json`.

Дополнен русский перевод интерфейса и меню; параметры подстановок проверяются при каждой сборке.

## Патчи

| ID | Изменение | Источник |
|---|---|---|
| APK-001 | ARM64 release AOT, удаление неиспользуемых иконок, обфускация Dart и исходные R8/resource shrinking. | `.avx1/PATCHES.json` |
| APK-002 | Один постоянный ID форка и закрытый ключ подписи; один актуальный APK. | `.avx1/PATCHES.json` |
| APK-003 | Flutter 3.47.8, стабильный Android SDK 37.2/build-tools 37.0.0; проверка подписи, ABI и 5004 теста. | `.avx1/PATCHES.json` |
| APK-004 | Дополненный русский перевод, проверка параметров и меню. | `.avx1/PATCHES.json` |
| APK-005 | SQLite, Dart JNI и ONNX Runtime/JNI из исходников: O3 ARMv8-A ThinLTO; проверка команд C/C++, экспортов и страниц Android 16 КиБ. | `.avx1/native-arm64.json` |

SQLite 3.53.4, dartjni 1.0.3 и ONNX Runtime/JNI 1.22.0 собираются из исходников NDK Clang с O3, ARMv8-A и ThinLTO. Проверяются API/JNI-экспорты, идентификаторы сборок внутри APK и выравнивание страниц 16 КиБ. Провайдеры CPU, NNAPI и XNNPACK сохранены. Готовые библиотеки Flutter engine, WebRTC, PDFium и AndroidX перечисляются отдельно; им и Dart AOT не приписываются флаги C/C++. Скорость на физическом телефоне не измерялась. Закреплённые исходники и требования совместимости: `.avx1/native-arm64.json`.

ThinLTO подтверждён для 486 файлов C/C++ ядра ONNX и 17 файлов JNI. 21 файл ручного ассемблера MLAS остаётся машинным кодом: LLVM bitcode LTO к нему неприменим. Исходный выбор оптимизированных ядер по возможностям CPU сохранён.

## Замеры

ARM64 APK от 24.10.2026 (`316e124d`): 92 667 875 байт; официальный v4.2.1 ARM64 APK: 97 324 692 байта. Размер **меньше на 4,78%**, но на 1,21% больше нашей сборки от 23.10.2026. Измерен объём загрузки и хранения при разных версиях инструментов, а не скорость приложения. [Точный состав библиотек, хеши и проверки](.avx1/measurements/native-release-316e124d.json). [Официальный пакет для сравнения](https://github.com/cogwheel0/conduit/releases/tag/v4.2.1).

Производительность на физическом телефоне ещё не измерялась.

## Лицензии и совместимость

Оригинальные LICENSE, notices и история лицензий сохранены. Точные исходники, инструкции сборки и закреплённые исходники зависимостей доступны по тегу релиза и ссылкам в его описании. Закрытые ключи подписи хранятся вне репозитория. Для APK используется собственный идентификатор приложения.

Локальное развёртывание дополнительно проверяет частные фильтр и Telegram-бридж владельца. Их исходники, настройки и данные не публикуются. Непроверенные изменения из PR/форков остаются кандидатами; принятые upstream исправления поступают через слияние исходных веток.
